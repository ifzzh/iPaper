# iPaper 1.8.0 — UI 第一部分：统一视觉规范、文献库与阅读器

已发布并固定摘要部署。正式浏览器验收、真实论文阅读与实际 Web 重启恢复通过，Web latest 已远端核对为本版本；两个 Worker 未重建。

源码提交 `556f0e9dc416a88ab040cfd87b08e0448e2c4875`，平台 `linux/amd64`。

## 用户可见变化

- 统一视觉规范：主色改为非绿的莫兰迪灰紫，浅深主题共用一套设计令牌，背景不再做绿色染色；成功等状态仍配文字或图标，不单靠颜色。
- 文献库：左侧范围与主题分组更紧凑，新增可逐条移除的已选条件与“清除全部”；论文条目密度提高（约 103px → 80px，1440 桌面一屏 9 条以上），长标题两行截断并保留全文提示；未选中论文时桌面端收起详情列。
- 阅读器：顶部工具栏压缩并按导航、文档版本、页码、缩放、问答分簇；左侧目录由大卡片改为紧凑行；AI 问答侧栏统一标题、会话、消息与输入层级。
- 公共组件：按钮、输入、标签、徽标、弹窗、菜单统一到同一套令牌与状态；图标按钮补齐可读名称与提示。

本轮只改表现层：不新增业务 API、数据库结构或数据流；不引入新的模型、MinerU、OCR、翻译、书目补全或论文下载调用；既有论文、阅读位置、译文、分析、聊天、书签、元数据、关键词与主题保持可用。规范见 [UI 视觉规范](../development/ui-design-system.md)。

## 验证与回退

发布门禁覆盖完整 Docker 非集成测试、前端类型/单元/构建、四份 Python 依赖审计、源码与三个部署镜像的 Trivy 扫描及 CycloneDX SBOM；真实论文的前后对比在文献库与阅读器两个核心页面按 1920/1440/1280/390 浅深主题记录，另有隔离合成数据的浏览器回归与主色/密度计算样式审计。完整证据保存在私有目录，不进入 Release 附件。

升级前重新检查任务并创建停写备份；回退使用本次备份的回退脚本恢复 Web 1.7.0＋Workers 1.2.0，继续使用当前数据库，保留用户数据与新产生的阅读状态，禁止用旧数据库覆盖。

## 正式产品验收

正式 AutoSci 原文与已有 BabelDOC 译文各 22 页、结构原文 237 块与 6 块已有译文在统一阅读器内复核；另抽查第二、第三篇论文切换，关闭重开、刷新、布局调整与实际 Web 重启后的阅读位置与历史恢复。既有元数据、关键词、主题、任务与聊天记录只读复核，不重跑整理、不新增付费请求。

密码登录在隔离候选完成；正式验收使用短期受控维护会话，不修改用户密码。具体实现取舍、实际/模拟边界与已知限制见交付记录。
