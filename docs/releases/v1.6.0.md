# iPaper 1.6.0：关键词标签

已发布并完成正式部署、阅读及重启验收。Web `latest` 已从远端核对为本版本摘要。源码提交 `a9c2634cea1ba502abec1b49d1d1e4b01a71d210`，平台 `linux/amd64`；版本 tag 保持不可变。

入库后后台本地提取关键词；在论文详情纠正标签，在文献库点击标签筛选。多个标签可以同时满足或任一满足，与文字、分类、收藏、Reading List 叠加。服务端返回准确数量、每页50篇及固定的跨页批次名单。

人工添加和确认受到保护；移除、清空、合并、删除与重启不能绕过自动排除。改名保留稳定ID，别名、合并和30天撤销有冲突检查。任务支持取消、重试和进程重启恢复。默认整理不产生模型、MinerU、OCR、书目或下载请求。模型增强使用interpret配置，经预检和明确提交才调用，每篇一次，失败保留已有标签。

本地提取仍可能漏掉关键词或保留不够精确的英文短语，不等同于人工标引。没有可用正文时不会用文件名凑标签。本阶段不包含主题分类、智能文件夹、笔记或Agent。使用与数据保护见[关键词说明](../development/keywords.md)。

只发布Web1.6.0；Translation和Document Worker复用1.2.0既有摘要，见[组件矩阵](../../docker/release-components.json)。新增jieba0.42.1仅进入Web，MIT声明随镜像提供，项目许可证不变。

备份包含当前SQLite及既有不可变产物。回退Web1.5.0时保留当前数据库、新标签表和纠正记录；再次升级识别回退期间的入库、书目修改与删除，不恢复旧库覆盖新数据。正式切换前已生成新的受限备份和持久回退脚本，并校验 dry-run；其中基线为 Web1.5.0，不能沿用前一发布中恢复1.4.0的脚本。

具体运行证据、真实论文截图、存量批次、模型授权及备份路径留在私有交付记录；公共附件只包含脱敏验证说明、组件矩阵和三组件SBOM。
