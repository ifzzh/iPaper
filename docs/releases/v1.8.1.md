# iPaper 1.8.1 — UI 第一部分返工：明亮、现代、舒展的工作台

已发布并固定摘要部署。正式浏览器验收、真实论文阅读与实际 Web 重启恢复通过，Web latest 已远端核对为本版本；两个 Worker 未重建。

源码提交 `6d872d878b6a2f35e4f2bc24d35cd1ec0608b943`，平台 `linux/amd64`。

## 用户可见变化

- **浅色成为主设计场景**：白与极浅中性灰承担大面，黑灰文字构成清晰对比，靛紫只落在关键动作与小面积选中态；界面不再使用绿色，成功等状态改为非绿语义色并同时带图标或文字。深色保留为显式阅读偏好，单独调校中性层次。
- **单一侧栏取代两层导航**：品牌、主导航（文献库／Daily arXiv／任务中心／设置）合并为一条安静的白色侧栏；窄屏时作为抽屉出现，键盘 Escape 与遮罩可关闭。
- **文献库重新构图**：新增真实页面标题与数量、范围标签（全部文献／收藏／Reading List）、一条工具栏（搜索、筛选、排序、刷新）；论文条目改为无边框行节奏（标题、作者·年份、少量标签、资产状态），悬停/选中才显示复选框与收藏；筛选与批量操作移入弹窗和上下文条，作者可展开查看全部。
- **阅读器**：AI 概览／深度解读／阅读正文的模式切换并入单条工具栏，正文成为视觉主体，左侧目录与右侧问答层次更清楚。
- **问答侧栏**：会话入口改为标题＋会话菜单＋溢出操作（新建／刷新／删除），消息改为助手白底排版与用户浅灰气泡，输入区改为整块带边框的输入组件（内联发送/停止）。
- **主题默认策略**：无显式偏好的账号默认浅色；不再跟随系统自动深色，也不再被浏览器自动深色改写（`color-scheme: light`）。已保存的 `light`/`dark` 原样保留。

本轮只改表现层：不新增业务 API、数据库结构或数据流；不调用模型、MinerU、OCR、翻译或书目服务；论文、阅读位置、译文、结构内容、分析、聊天、书签、元数据、关键词与主题全部保留。规范见 [UI 视觉规范](../development/ui-design-system.md)。
