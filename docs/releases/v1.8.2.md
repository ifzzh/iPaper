# iPaper 1.8.2 — UI 第一部分定点收尾

已发布并固定摘要部署。正式浏览器验收、真实论文阅读与实际 Web 重启恢复通过，Web latest 已远端核对为本版本；两个 Worker 未重建。

源码提交 `669f7b269de20cfb20f723d4df1c21396a9a234f`，平台 `linux/amd64`。

## 用户可见变化

- **译文与结构阅读工具栏**：关键控件保留可用宽度，文档标题先让出空间，低频控件在宽度不足时整体换行；不再出现「版式译文」被压成"版"、「适合宽度」只剩"适"、`/ 22` 断行等情况。覆盖 1920/1440/1280/390 与双侧栏同时打开的桌面中间尺寸。
- **文献库分页**：补回独立的布局——「选择当前页」单独靠左，范围与页码弱化显示且不换行，翻页按钮保留 ≥28px 点击区；窄屏只缩小字号与间距。
- **主题计算样式**：阅读器懒加载 PDF.js 样式后，显式浅/深主题的 `color-scheme` 不再被改回 `light dark`，原生控件与滚动条跟随用户选择；PDF 页面与图表原色不变。
- **研究主题回到侧栏**：文献库状态下，研究主题树直接显示在单一侧栏里（含待整理计数、折叠与管理入口），不必先打开筛选弹窗；关键词与组合筛选仍在弹窗中。
- **导入入口统一**：文献库页头不再重复放「导入文献」，保留顶栏的全局入口与空状态的上下文入口。

既有论文、阅读位置、译文、结构内容、分析、聊天、书签、元数据、关键词与主题全部保留；1.8.1 的明亮构图、单一侧栏、无边框列表与问答输入组件保持不变。规范见 [UI 视觉规范](../development/ui-design-system.md)，收尾记录见私有 `.devnotes/ipaper-ui-1.8.1-closeout.md`。
