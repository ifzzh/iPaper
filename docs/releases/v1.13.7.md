# iPaper 1.13.7

Web 1.13.7 修复笔记在切换视图、处理冲突和等待限流时的保存问题，并将摘录回访绑定到实际来源。两个 Worker 复用 1.2.0，无数据库结构变化。

## 变化

- 笔记按账号与论文保留同一个保存会话。切换页签、收起侧栏或切换原译文后，未决冲突仍须明确选择，不会自动用本地稿覆盖服务器。
- 冲突决定只确认点击时提交的版本；等待期间输入的新内容继续保留并在确认后保存。面板和编辑器中的决定按钮使用同一队列。
- `Retry-After` 等待由定时器唤醒，继续输入、离焦或重新打开面板不会递归重入保存过程，也不会提前发送请求。
- 摘录回访先校验受控批注，再切换到确切 PDF 文档或结构结果及原译文侧；对应页面或内容块加载后才显示已定位。未保存的笔记保留，异步 PDF 加载不会再次抢占页签。

## 验证与发布状态

此文件随确定的发布源码提交。发布门禁、镜像摘要与部署结果在正式发布后补充；源码版本号本身不代表已部署。验证包括完整 Docker 非集成测试、前端类型/单元/构建、镜像内静态前端的笔记时序回归、安全扫描与三组件 SBOM。真实模型、MinerU、OCR、翻译不在本次验收调用范围内。

## 组件与回退

目标组合为 Web 1.13.7＋Translation Worker 1.2.0＋Document Worker 1.2.0。完整固定摘要见发布完成后的 [组件矩阵](../../docker/release-components.json) 与 GitHub Release 正文；不为未变化的 Worker 制造新版本。

回退基线为 Web 1.13.6＋Workers 1.2.0，保留当前数据库与已有笔记、冲突副本和来源记录；回退会重新暴露上述旧前端缺陷。未保存稿是浏览器会话内存，离开页面有提醒，不承诺浏览器重启后恢复。私人验收证据、备份、扫描 JSON 与 SBOM 不作为公开 Release 附件。
