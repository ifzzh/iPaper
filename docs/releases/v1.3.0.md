# iPaper 1.3.0 — 单篇概览、深度解读、问答与导出

1.3.0 已发布并完成正式部署验收。发布提交 `6a74a1dae73696f7bf4476bc504bb8f6e1546188`，平台 `linux/amd64`；组件完整摘要、验证摘要及三组件 SBOM 随 [Release](https://github.com/ifzzh/iPaper/releases/tag/v1.3.0) 提供。发布后的文档提交不改变该 tag 或版本镜像。

已有结构解析的论文可以直接生成独立 AI 概览和图文长解读，无需重复 MinerU 解析，也不要求先翻译全文。作者摘要继续作为元数据保留。概览、解读、正文与同一问答侧栏通过来源和返回操作衔接；刷新恢复分析位置与所选会话。

局部问答使用选区/当前段落或分析证据卡的已核实原文。整篇问答对全部可用原文进行问题相关的证据选择，显示检索与实际使用范围；不会截取开头后声称读完全文。已使用且被引用的编号才成为来源链接，未知几何的旧 Markdown 只返回摘录。模型未接收图像时明确只依据正文、表格文字和图注。

恢复 Markdown、含授权图片的离线 ZIP 和浏览器打印/另存为 PDF。旧 `result.md` 与历史图片保持可读可导出，缺少原始 PDF 时也不隐藏历史分析。无自动解析、自动翻译、隐含模型连通测试或缓存读取付费调用。

## 验收边界

最终发布归档的 Docker 完整非集成测试 324 项、84 个子测试通过，1 项集成测试按规则排除；干净前端安装、类型检查、11 项单元测试、构建及依赖审计通过。真实浏览器检查后补齐慢响应切换回归，避免旧分析短暂显示在新标题下。

真实验收使用 AutoSci 已有完整 237 块 / 239 原文单元，未新增 MinerU 解析。独立概览、约 2 万字符的详细图文解读、同问题的局部与整篇问答经真实 Flask 路由生成并保存。局部证据不足时正确说明缺失；全文实际选择 46 单元，后部实验数字与局限分别核对原文第 11、13 页。模型接收正文、表格文字和图注，不接收图像像素。全文选择限制与实际使用范围在界面显示。

先前 4 次响应未完整，随后一段省略号摘录被逐字校验拒绝。修复后只在唯一、按序、逐字匹配的原文内恢复省略片段，不能模糊猜测来源。复用保留的 5 段回答，仅重新汇总并执行尚未完成任务。用户授权有界调整重试；累计 19 次真实请求，保守输入上限 289234、输出上限 45056 token，SDK 自动重试 0。旧四次实际供应商用量缺失，不将上限当作计费统计。

Edge 实际验收原文及已有译文均 22 页、文字和画面非空；真实分析覆盖 1920/1440/390 浅深视图、来源返回、历史和刷新位置。Markdown 图片包断网打开，13 处图片均可读；浏览器打印 23 页，检查文字、图表、分页和来源摘录。生产论文截图与原始回答仅私有保存，不作为公开附件。错误、取消、重启与隔离场景使用假供应商，不能与真实调用结果混记。

最终兼容三组件安全扫描通过，四份 pip-audit 报告均为零已知漏洞，三份 CycloneDX SBOM 已生成。高危/严重配置、secret 及镜像扫描通过既有门禁。本次未新增漏洞例外；仍保留 [既有例外清单](../../security/vulnerability-exceptions.json) 中的 PYSEC-2026-3447、CVE-2026-23949、CVE-2026-24049、PYSEC-2026-161、PYSEC-2026-248、PYSEC-2026-249、PYSEC-2026-2280、PYSEC-2026-2281，适用目标、理由见清单，到期日均为 2026-12-08。公开发布时附最终镜像对应报告及 SBOM。

真实旧 1.2.0 镜像的降级、旧功能新增聊天/设置、再升级演练通过；原有 36 张表结构不变，新结果与文件保留。正式部署采用停止写入后的 SQLite、不可变产物、全部论文与配置备份，回退保留当前数据库及新增结果；不覆盖用户在升级后新增的数据。
