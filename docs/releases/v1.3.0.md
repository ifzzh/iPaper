# iPaper 1.3.0 — 单篇概览、深度解读、问答与导出

状态：候选，尚未发布或正式部署。不得将下述实现范围代替最终验收证据。

已有结构解析的论文可以直接生成独立 AI 概览和图文长解读，无需重复 MinerU 解析，也不要求先翻译全文。作者摘要继续作为元数据保留。概览、解读、正文与同一问答侧栏通过来源和返回操作衔接；刷新恢复分析位置与所选会话。

局部问答使用选区/当前段落或分析证据卡的已核实原文。整篇问答对全部可用原文进行问题相关的证据选择，显示检索与实际使用范围；不会截取开头后声称读完全文。已使用且被引用的编号才成为来源链接，未知几何的旧 Markdown 只返回摘录。模型未接收图像时明确只依据正文、表格文字和图注。

恢复 Markdown、含授权图片的离线 ZIP 和浏览器打印/另存为 PDF。旧 `result.md` 与历史图片保持可读可导出，缺少原始 PDF 时也不隐藏历史分析。无自动解析、自动翻译、隐含模型连通测试或缓存读取付费调用。
