# iPaper 1.15.0

文献库采用独立列表/详情工作面、统一的筛选与视图工具带和可关闭详情；阅读器重新分配标题、模式与工具位置，阅读时主导航可收窄。主题通过缩进、文件夹和上下文菜单浏览，维护操作按需出现。问答及笔记继续在同一阅读空间使用；明亮中性色与少量靛紫强调保持一致。

PDF 明确区分首开与再开：小文件流式读取减少往返，大文件保留分块；优先渲染当前页，避免重复缩放及旧/新译文入口双加载。当前页面会话允许有界复用解析结果，每次仍鉴权与核对 ETag，账号切换清除；稳定文件摘要按 owner 与文件变更通知复用，不能可靠监听时重新扫描。

- 组件：Web 1.15.0，两个 Worker 继续复用 1.2.1；无数据库 schema 改动。
- 不触发新的模型、MinerU、OCR、翻译请求。
- 本机预览仅能说明该场景下的性能，不保证所有 PDF 或网络条件具有相同耗时。
- 回退基线为 Web 1.14.0 + Workers 1.2.1；切回镜像保留当前数据。

详见[界面规范](../development/ui-design-system.md)与[性能边界](../development/performance.md)。
