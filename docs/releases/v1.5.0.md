# iPaper 1.5.0：论文入库识别、元数据补全与编辑

PDF 安全入库后即可阅读，公开书目补全在后台执行。统一文献库和详情现在支持：

- 完整有序作者、机构、发表信息、DOI、arXiv ID／版本和有来源的项目链接。
- 按修订编辑，保护人工修改与主动清空；并发冲突保留草稿。
- 单篇及跨页批量补全、持久任务、取消、失败重试和重启恢复。
- 根据当前信息复制或下载 BibTeX；重复提示保留文件和不同版本，不自动合并或删除。

元数据刷新不再重命名文件或移动资产，标题保存不再暗中联网覆盖其他字段。已有阅读、双翻译、分析、聊天及阅读定位继续使用原有绑定。本阶段没有新增自动标签、主题分类、笔记或 Agent；元数据流程不使用模型、MinerU 或 OCR。

书目来源仍有边界：arXiv 可能限流或超时，DBLP／OpenReview 可能拒绝当前网络的请求。无法核实的候选需要用户确认，失败不会被标成补全成功，也不会清空已有可读内容。

本次仅发布 Web，两个 Worker 复用既有版本。新增 SQLite 表采用兼容扩展；回退需保留当前数据库及新数据，不能使用旧库覆盖升级后的用户修改。使用方式与来源约束见[元数据说明](https://github.com/ifzzh/iPaper/blob/main/docs/development/metadata.md)。
