# iPaper 1.13.0 — 阅读高亮、批注与单篇笔记

候选发布记录；Registry 摘要及最终门禁结果在发布验收后填写，不能视为已经部署。

## 目标

读到重要段落 → 高亮或写批注 → 记录自己的理解 → 关闭后仍能找回 → 一键回到来源 → 导出笔记。范围限定在**现有阅读器**内的单篇高亮、批注、主笔记、保存已有回答与 Markdown 导出；全库富文本工作区、双链、知识图谱、跨论文 RAG 与带批注 PDF 导出留待后续。**本轮不新增任何真实模型 / MinerU / OCR / 翻译调用**。

## 能力

- **高亮与批注**：在原文 PDF、已有 BabelDOC 译文与结构正文中选中文字，可保存高亮或简短批注；四种淡色（淡紫/灰蓝/雾粉/暖黄，规范色值）、批注可修改、删除并**明确撤销**。高亮是持久记录，不是当前 DOM 的临时效果。
- **批注侧栏**：阅读器右侧「问答 / 批注 / 笔记」页签。批注按阅读顺序列出摘录、自己的批注、文档类型与页码/块来源，可按原文/版式译文、结构内容、仅批注筛选与搜索；点击条目定位来源并展开详情，来源失效时给出说明而不是跳到别的内容。
- **单篇主笔记**：每位用户每篇论文一份 Markdown 笔记，编辑/预览、1.2 秒防抖自动保存与状态（保存中/已保存/保存失败），可把摘录明确插入笔记并保留可回访来源。笔记依附论文，不随主题或关键词迁移。
- **保存已有 AI 回答**：助手消息提供「存入本篇笔记」，只复制已持久化的内容与当时的来源标签，**不重新问模型**；正在流式生成或未成功保存的回合无法保存；重复点击幂等。
- **Markdown 导出**：含论文标题、作者、arXiv/DOI、导出时间、笔记正文、摘录与批注、来源记录；不包含密钥、会话令牌或服务器绝对路径；`?annotations=0` 可只导出正文。

## 来源定位与版本

- PDF（原文与版式译文各自独立）保存页号与**归一化行矩形**（按页面旋转反算到未旋转坐标系），多行逐行记录；缩放、旋转、适合宽度、窗口变化与虚拟页面重渲染后位置仍正确，不覆盖段间空白或相邻栏。
- 结构内容保存块、字段（`text`/`caption`/`cell:r:c`）、文字范围与译文修订；重新解析或重译后**先按存下的摘录校验当前文本**，不匹配则不画高亮并提示来源变化。
- 扫描件/无文字层按**页级记录**降级保存，不自动 OCR、不伪造文字高亮。
- 源文件被替换或结果失效时保留摘录，明确 `stale`/`canNavigate=false` 与原因，不静默跳到新内容的相似段落。

## 数据与边界

- 新增 `reading_annotations`、`reading_notes`、`reading_note_entries`、`reading_note_conflicts`（纯增量、旧版本可读写）。所有读写 owner 隔离，写入前校验论文/文档/结果归属，沿用认证、CSRF 与限流。
- 上限：摘录 8,000 字符、批注 2,000 字符、笔记 256 KiB、每篇有效批注 2,000 条、列表分页（≤200）。
- 并发：笔记保存做修订校验，冲突时把来稿存为**可恢复草稿**并让用户明确选择保留哪一份；摘录/回答插入同事务读取-追加-写回且校验修订，不会吞掉并发内容。
- 论文文件、哈希与译文不被修改；备份沿用现有数据库停写快照（新表在同一 SQLite 文件中）。

## 组件

仅 Web 1.13.0 发布；Translation/Document Worker 复用已验证 1.2.0 摘要。

## 验证

- 后端 `tests/test_paper_notes.py`（7 项）：批注生命周期与撤销、owner 隔离与 CSRF、锚点/尺寸/颜色/类型校验与页级降级、主笔记冲突草稿与显式解决、摘录插入的修订校验与去重、回答保存的归属校验与幂等（含 user 角色/不存在/未持久化）、导出内容与私有路径剥离、来源失效后的降级。
- 浏览器 `frontend/unified-tests/notes.spec.ts`（独立配置 + 合成结构化夹具，3 项）：选中 → 高亮/批注 → 侧栏 → 刷新后仍在且页面绘制高亮 → 点击回访；笔记自动保存 → 刷新恢复 → 导出内容一致；owner 隔离与非法锚点拒绝；把种子回答存入笔记且重复点击不产生副本。
- 全量门禁：Docker 非集成测试、前端类型/单元/构建、统一套件与各专项（含 structured/understanding/额度/Daily/主题）、四份 pip-audit、Trivy 源码与三镜像、三份 SBOM、`dev`/`main` CI。
- 正式环境：部署后以真实账号在原文与结构内容各保存一条批注、写一段笔记、保存一条已有回答并导出，随后**只清理本轮创建的测试记录**，保留用户新增内容；同时回归首页、文献库、Daily、阅读位置与既有问答。

## 限制与回退

- 本轮不含全库笔记工作区、双链、知识图谱、跨论文检索、自动生成笔记与带批注 PDF 导出。
- 结构内容的文字高亮以存下的范围与摘录校验为准；无法匹配时只显示块级来源与说明。
- 回退基线 **Web 1.12.1 ＋ Workers 1.2.0**；新增表可空且旧版本忽略，回退只切镜像，不恢复旧数据库覆盖新增记录。
