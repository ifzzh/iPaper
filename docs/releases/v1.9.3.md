# iPaper 1.9.3 — 依赖安全补丁（anyio）+ 主题侧栏加载修复

候选发布记录；Registry 摘要及最终门禁结果在发布验收后填写，不能视为已经部署。

## 为什么发布

2026-09-19 的依赖门禁（`scripts/security_scan.sh dependencies`，pip-audit 使用实时公告库）报出 **anyio 4.12.1** 的两个新披露漏洞：

- `CVE-2026-63374`
- `CVE-2026-64847`

修复版本为 **4.14.2**。Web 与测试依赖集被标记 BLOCKED，`dev`/`main` 的 `Security gate` 因此失败；已部署的 1.9.2 镜像同样包含该版本，所以本次直接以补丁版本修复并重新部署。

## 变更

- `docker/requirements-web.txt`、`docker/requirements-test.txt`：`anyio==4.12.1` → `anyio==4.14.2`。
- `uv.lock`：anyio 4.14.2（含 PyPI 校验用的 sdist/wheel 摘要与上传时间），其余依赖保持不变。
- Translation/Document Worker 的依赖集不受影响（worker 集本身已是 anyio 4.15.1，document 集不含 anyio），两个 Worker 不重建。
- 同时包含 **1.9.2** 的主题侧栏修复：后台刷新不再显示阻塞加载提示、只有最新请求写状态、请求 30 秒超时失败、常驻面板轮询改为 30 秒且仅在可见/无在途请求时发起、变更改为显式刷新。

## 验证

- `scripts/security_scan.sh dependencies` 四份依赖集全部通过（无 BLOCKED）。
- 完整 Docker 非集成测试、前端类型/单元/构建、统一套件与各专项回归、源码与三镜像 Trivy 扫描、三个 CycloneDX SBOM，`dev`/`main` CI 全绿。
- 正式部署后复核：Web healthy、`/readyz` 正常；只读探针确认主题侧栏加载提示占比 0%、`/api/topics` 请求频率与 1.9.2 一致（约 3 次/20 秒）。

## 限制与回退

- anyio 4.14.2 是公告给出的修复版本；本轮只做该依赖的定向升级，不连带升级其它包。
- 回退基线为执行前的 **Web 1.9.2 ＋ Workers 1.2.0**（注意 1.9.2 含受影响依赖）；如需回退，建议只回退到 1.9.2 的界面行为而不是长期保留该依赖版本。本次没有数据库变更。
