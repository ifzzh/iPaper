# iPaper 1.4.0 — 单篇日常阅读工具

在统一阅读器中提供全文搜索、章节目录与书签、PDF 段落缓存译文、明确触发的划词翻译和图表查看。保留双翻译阅读、概览、长解读、两种问答范围、可信来源与离线导出；没有增加笔记、批注、Agent、向量库或第四个常驻服务。

## 使用与边界

- 阅读工具栏的搜索按钮或 Ctrl/Cmd+F 搜索完整文档。PDF 独立提取各页文本，结构阅读搜索所选版本全部块；选择原文、译文或两者。无文本和提取失败分别提示，不自动 OCR。高亮来自实际文字映射，无法映射只定位页面。
- 左侧切换目录、缩略图、书签。PDF 优先使用内置目录，原文可复用可靠结构标题；不把原文目录套到 BabelDOC。书签绑定文件或结果版本，支持命名、改名、删除和重启恢复。每篇最多 200 条、每账号 5,000 条。
- 原始 PDF 单击可靠段落区域查看当前结构译文版本已有结果。未译、失败、过期如实呈现，不因点击创建任务。只有经过验证的坐标参与命中。
- PDF 或结构正文选词后点击“翻译”，先显示语言、结构化翻译模型及处理范围，再由明确提交创建持久任务。最多 2,000 字符、一次请求、120 秒，SDK 不自动重试。缓存读取零调用；关闭浮层只停止显示，取消任务不承诺供应商取消或费用。
- 图片、宽表格及块公式可展开；支持适合窗口、缩放、平移、横向浏览及关闭后返回。仅访问已有授权资产，不调用图像模型、不下载外站图片。

## 验收记录

最终源码归档执行 Docker 完整非集成测试：334 项、84 子测试通过，1 项集成测试按规则排除。前端干净安装、类型检查、16 项单元测试、构建、依赖审计通过。Edge 新阅读工具 3 条、既有统一产品 13 条、双翻译及单篇理解各 1 条完整流程通过；测试数量不替代以下实际阅读检查。

300 页自制 PDF 从第一页命中第 299 页唯一文本，核对真实文本 Range、旋转、缩放、连字、换行及取消。当前机器该轮扫描 880ms；页面 JS heap 约 11.66MB→12.84MB，不包含 Worker/GPU/画布原生分配，不作为性能承诺。无目录、扫描 PDF、分页提取异常与超限文字有独立降级。

AutoSci 保留的原文与 BabelDOC PDF 均实际渲染 22 页；结构搜索覆盖 237 块，译文覆盖 6 块。单击已有段落、切换和缓存读取没有新增模型或 MinerU 任务。保存 1920/1440/390 浅深视图，检查实际文字、渲染画面、图表返回、网络、控制台和阻断式 CSP。生产论文截图只私有保存。

经本轮独立授权，在隔离应用中使用当前结构化翻译 `qwen3.8-flash` 完成两处真实选区验收（作者列表和研究背景正文）；每次 1 请求、输入预算 2,000／输出预算 512 token、120 秒，无自动重试，复读缓存新增请求为 0。额度是保守上限，不是计费统计。MinerU 新请求为 0。失败、超时、取消、去重、配置变化及晚到响应由假供应商验证，与真实调用分别记录。

兼容组件安全门禁包括四份 requirements 审计、源码配置/secret、三个镜像扫描及 CycloneDX SBOM。本轮不新增依赖或漏洞例外；既有例外及到期日见 [例外清单](../../security/vulnerability-exceptions.json)。最终报告、发布提交、平台与摘要随 [Release](https://github.com/ifzzh/iPaper/releases/tag/v1.4.0) 提供。
