# iPaper 1.14.0

文献库支持列表与真实 PDF 首页卡片视图，展示标题、作者、标签和中文概述。智能整理按「概述 → 标签 → 研究主题」执行，先保存概述，再整理标签；自动整理默认关闭，历史论文须显式选择并确认调用计划。已有 Daily 中文概述和成功结果可复用，生成概述不会覆盖作者摘要。元数据补全增加 USENIX 出版页面识别，可从真实 PDF 首页的出版信息核验论文身份。

PDF 使用更大的按需分块、较小的预渲染窗口和附近页面保留区；文献库批量读取概述与标签，共享主题目录，并合并同时在飞的重复 GET。封面串行复用解析 Worker，内存缓存最多 12 MiB，每次复用先认证并核对文件版本。公共 JS/CSS 支持预压缩与内容哈希缓存，私人 PDF/API 的鉴权和禁止缓存策略保持不变。主题树及折叠区统一为轻量加号/减号，保持明亮中性布局和既有浅深主题选择。

本轮同步修复运行依赖的安全公告。源码 Python 支持范围提升到 3.11–3.13，Docker 继续使用 3.12；两个 Worker 因依赖变化发布 1.2.1，BabelDOC 业务版本不变。组件摘要以仓库组件矩阵及 Release 正文为准。

验证覆盖全量非集成测试、前端类型/单元/构建、原译文阅读、300 页搜索、批注笔记、概述整理、封面重访与权限失效、四套依赖审计和三镜像扫描。正式性能计时只代表同一主机、同篇论文和当次网络条件，不能作为所有论文的速度保证。本轮验收不运行真实模型、MinerU、OCR 或翻译。

升级前停止接收任务、暂停 Daily 并等待在飞轮次结束，创建一致性备份。回退基线为 Web 1.13.7 与两个 Worker 1.2.0，保留当前数据库和新增数据；新增整理任务须终止或收尾后再回退，不自动重发结果未知的模型请求。漏洞例外以 [版本化例外清单](https://github.com/ifzzh/iPaper/blob/v1.14.0/security/vulnerability-exceptions.json) 为准，原始报告不作为公开 Release 附件。

## 正式验收

已按三个固定摘要部署，三服务健康，Web latest 回拉摘要一致。原文与版式译文均为 22 页，真实 Web 重启后阅读位置和缩放模式恢复，内部 Worker 鉴权通过，Daily 调度已恢复。

同主机、同论文、同顺序的一次冷加载观测中，文献列表可见时间为 488 → 272 ms，原文文字层就绪为 2074 → 964 ms；译文为 2100 → 1965 ms。初始观测窗口内原文文件请求 17 → 10，译文 48 → 21，邻近渲染页 5 → 3。浏览器路由拦截使 HTTP 缓存关闭；这些是一次样本观测，不能当成所有论文的固定加速比例。公共 PDF 解析脚本从约 2.40 MB 压缩为 0.51 MB。

`nsdi25-xing` 已完成规范书目补全；概述生成与标签/主题整理仍须按页面计划确认，自动模型整理默认关闭。验收无真实模型、MinerU、OCR 或翻译调用。
