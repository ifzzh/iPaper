# iPaper 1.10.0 — 独立研究首页

发布源码 `98798e55efa616c9e2edcfc4d54fd46b0b5ec7ca`，平台 `linux/amd64`。Web 1.10.0 已发布；版本镜像已从 Registry 回拉，摘要、平台与源码 revision 均已核对。

根路径现在打开独立研究首页，侧栏可直接进入文献库。首页包含继续阅读、真实文献和阅读统计、7/30 天阅读趋势、年度/12 周阅读热力图、一级研究主题与 Daily arXiv 入口。浅色界面以白色与浅灰为主体，使用少量蓝紫强调；深色仍是明确的用户偏好。

热力图随首页正常滚动，不再挤占文献库列表。已有论文链接、论文页签、原译文及阅读位置仍沿用现有阅读器；首页读取已有结果，不触发模型、MinerU、OCR、翻译或论文下载。日期与分日统计继续使用北京时间（UTC+8）。

统计来自当前账号已有数据；请求失败显示重试，不把失败伪装为零。继续阅读基于当前打开的论文及保存的活动论文；没有打开记录时明确显示“开始阅读”。主题可以重叠，不视作互斥比例。Daily 展示已有批次，不自动刷新供应商内容。
