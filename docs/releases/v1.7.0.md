# iPaper 1.7.0 — 研究主题与多主题浏览

已发布并固定摘要部署。正式主题浏览、阅读与实际 Web 重启恢复验收通过，Web latest 已远端核对为本版本；两个 Worker 未重建。

源码提交 `a8e98d03ec9ddfd1b7856ab370a1233f02e1b0cd`，平台 `linux/amd64`。

## 用户可见变化

- 入库后本地自动归类；手动/迁移主题不阻断初始化，已有主题可绑定方向，明确预览后扩展体系。
- 少量稳定方向、多主题、父级去重浏览，与关键词、搜索、收藏及 Reading List 叠加。移动端使用同一筛选面板。
- 加入、分支移出、清空、改名、层级、合并、恢复和撤销。人工纠正持久保存，批量操作原子提交、幂等重试和修订冲突保护。
- 导入与 Daily 使用独立逻辑主题关系；旧分类兼容迁移，旧物理移动/删除入口退役。论文 UUID、路径和资产不变。
- 主题 BibTeX/arXiv 导出、筛选/折叠偏好、持久整理任务和重启恢复。

分类使用已采用内容和已有原文，不请求模型、MinerU、OCR、书目补全或下载。不提供模型增强占位入口；未覆盖方向保留待整理或人工维护。独立样本有机器人记忆漏分，不能将任务成功视为分类准确率。详见 [使用和限制](https://github.com/ifzzh/iPaper/blob/main/docs/development/topics.md)。

## 验证与回退

发布门禁覆盖实际 Edge 同源浏览、合成上传与真实 Document Worker、跨用户/CSRF、250篇跨页组合筛选、批量事务、人工纠正、真实进程恢复和真实1.6镜像回退再升级。既有入库内容独立检查分类聚合，真实论文及运行证据私有保存。本轮完整Docker非集成442测试和84子用例、前端16测试、干净安装/类型/构建、npm audit0、四份Python依赖审计、源码及兼容三镜像Trivy、三个SBOM、三个远端分支CI均通过。已存在的明确漏洞例外见附件及仓库 `security/vulnerability-exceptions.json`，不新增宽泛例外。

升级前重新检查任务并创建停写备份，涵盖完整 SQLite、纠正/任务记录、既有论文和不可变产物及受限配置。回退使用本次备份的 `rollback.py` 恢复 Web1.6.0＋Workers1.2.0和渠道，继续使用当前数据库，保留新增表及新用户数据，禁止用旧数据库覆盖。`scripts/validate_topics_rollback.py` 仅用于隔离夹具。

## 正式产品验收

固定的11篇已入库论文全部完成一次本地整理，未入库 Daily 不参加。形成4个一级方向和1个二级方向：动作理解与机器人6篇（动作理解5篇）、智能体研究4篇、计算机系统3篇、计算机视觉3篇；跨分支可重叠，不能相加当总数。逐篇核对实际内容与聚合，0待整理不等于没有误分或漏分。

正式 Edge 在1920/1440/390浅深视图通过父级去重、收藏交叉、返回阅读；AutoSci原文/已有译文各22页实际文字和画面、237块结构搜索、6块缓存译文、概览/解读、来源返回、历史会话、元数据/BibTeX、Daily/任务日志/设置及跨标签退出通过。已有导出包在离线Edge中加载13张本地图片，打印22页并抽查页面。密码登录在隔离候选完成；正式验收使用短期受控维护会话，未修改用户密码。

实测Web重启后任务终态和阅读/主题恢复；727个持久文件哈希、原UUID/路径、已有聊天/结构/书目/标签记录不变。另一个文件为正常更新的派生搜索索引；既有Daily正常新增的未入库书目单独记录，不算主题回填。主题工作新增模型/MinerU/OCR/翻译/下载调用均为0。

新停写备份及升级后日常一致性备份已验证。持久回退脚本dry-run确认恢复Web1.6.0、原Workers及latest，保留当前数据库和产物。没有在生产再次回退；实际回退再升级在隔离环境运行旧1.6.0镜像验证。私有部署记录包含本轮备份路径和操作命令。
