# 关键词标签

关键词用于当前文献库的查找和整理。它与作者提供的原始关键词、书目信息和分类独立，不能据此改写 BibTeX 或推断论文主题类别。

## 使用

- 实际入库后自动本地提取，PDF 可先阅读；设置里的“自动整理关键词”控制后续整理。打开详情、读取缓存和改名不调用模型。
- 在详情中添加、移除、确认标签，或点击“整理标签”。批量区可选择当前页，也可固定全部匹配名单。任务中心显示进度、取消和明确重试。
- 点击标签筛选，多个标签默认同时满足，可切换任一满足；与标题／作者／摘要检索、递归分类、收藏及 Reading List 叠加。每页 50 篇，数量和批量名单来自同一服务端查询。
- “管理标签”支持改名、别名、合并、全库删除与恢复。改名保留 ID；从本篇移除不会删除标签或论文。历史操作可在 30 天内撤销；若相关数据已被再次编辑，则拒绝覆盖新修改。
- 模型增强是明确选择的单独操作，使用当前 interpret 配置。每篇最多一次请求、8,000 输入 token 的保守上界、1,024 输出 token、120 秒，无 SDK 自动重试；内容超预算时不能提交，可明确改为仅使用已确认标题和作者摘要后重新预检。结果未知须明确重试，不能假称供应商已取消。

## 输入和提取

采用已确认的标题、作者摘要和保留的原始关键词。摘要不足时复用同一文件 SHA 对应的首页检查缓存，必要时读取已有结构原文或旧 Markdown；不会创建快照、复制图片、访问书目供应商、重新解析或下载论文。未采用书目候选、AI 概览、深度解读和兴趣匹配词不进入输入。Daily 生成词只有在当前标题／摘要中有依据才作为候选，来源不标成作者原词。未入库 Daily 记录不处理。

本地算法组合中文分词与词性短语、英文连续词组、词频与共现、标题权重、泛词过滤及嵌套去重。最多 8 个自动标签、每个 48 字；人工标签每篇最多 128 个、名称最多 64 字。扫描最多 200,000 字符、12,000 候选及 15 秒提取时间，逐段检查取消，记录实际覆盖范围。词表仅归一可靠同义词；未知术语仍可由文本独立提取。无法可靠中文化的英文短语保留原文。短摘要和复杂长标题仍可能漏词或留下不够精确的短语，用户可纠正或明确请求增强；没有有效内容时不以文件名凑词。

模型仅返回 JSON 标签和逐字存在的证据，不能执行工具、提供任意文件路径、修改书目或自动创建全局别名。增强缓存按 owner、论文、有效原文、方法／提示词版本及服务端配置修订区分。模型失败保留此前标签。成功的本地整理与模型增强形成同一自动层的新修订，人工关联独立受保护。

## 数据与并发

SQLite 增量表记录稳定 owner UUID 标签、别名、论文关联、自动排除、合并重定向、任务／事件和撤销日志。原始 `keywords`、作者摘要、UUID、文件名、路径及阅读产物不变。自动来源仅保留有界摘录，不复制论文正文或图片。

- 主库单事务提交标签、纠正修订、成功任务检查点。提交检查输入指纹、人工修订、任务取消、论文存在和 owner；晚到任务不能覆盖新纠正。
- 移除和清空记录永久自动排除；只有重新添加或明确重置纠正才解除。改名保留旧名映射，合并传递排除和人工关联，全库删除保留 tombstone。撤销记录过期不会删除这些保护。
- 独立持久队列：全局两个本地执行槽，每用户一个运行项，最多 20 个活跃批次；付费增强同时服从既有模型并发槽。取消停止领取后续工作；未发请求的本地项在重启恢复，已发送且未确认的模型项标为中断，不自动重发。
- 文献库筛选、首页元数据索引及分类计数直接读取主库，无文件系统扫描及 FTS 前 100 条截断。壳层仍读取用于标签页标题和详情的元数据索引，列表自身使用服务端分页；这不是全文内容预加载。元数据自己的索引失败及重试保持原有机制，不重做关键词或模型请求。固定名单存活 24 小时；删除项跳过，不自动补入新论文。
- 旧版本回退期间的新入库、采用字段修改与删除在再升级时对账。首次安装仅登记历史基线，存量整理需明确批次；不自动启动上一轮书目回填。

全部写入要求会话、CSRF、owner、大小及修订检查。文本按普通文本渲染，沿用严格 CSP。标签、排除和任务仅保存在 SQLite，一致性备份自动包含；日常备份及回退见 [部署说明](../operations/deployment.md) 和 [一致性备份](../operations/structured-backup.md)。回退保留当前数据库、新表和既有不可变产物，不能用旧库覆盖新增数据。
