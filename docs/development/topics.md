# 研究主题与多主题浏览

主题表示研究方向，关键词用于细节筛选。1.7.0 仅更新 Web，两个 Worker 继续使用 1.2.0。发布和部署状态见 [发布记录](../releases/v1.7.0.md)。

## 使用

左侧点击主题浏览，勾选多个主题取并集；父主题包含所有有效后代并去重。主题可与收藏、Reading List、文字和关键词 AND/OR 条件叠加。清除主题不清除其他条件。小屏从“筛选研究主题”打开抽屉，折叠和筛选偏好独立保存。

详情可加入、移出、清空或重新整理论文主题；列表支持当前页及全部匹配的固定名单。批量人工调整在一个事务中提交，冲突不产生半批结果。未收到确认时可以重试同一请求，修订冲突需重新核对。保存期间不关闭窗口；后台整理提交后可关闭，取消在任务中心操作。

管理面板支持创建、改名、上级、顺序、方向绑定、合并、删除、恢复和近期撤销。删除父主题将子主题上移，不删除论文；恢复节点不自动恢复移除关系。主题成员可下载当前 BibTeX 或复制去重后的 arXiv 链接。

## 内容和体系

本地分类复用已采用书目和匹配当前 PDF 的已有原文，不使用未采用候选、AI 解读或兴趣命中词，不执行关键词批次。通用定义要求有限文本窗口中的研究对象与方法/场景共同支持，孤立的 memory/cloud 不强制归类；没有支持时保留待整理。

首次从已有入库内容激活少量一级方向，二级需不同论文共同支持。手动或迁移主题不阻断初始化；与标准名称及层级精确对应的人工节点可绑定定义并保留 ID，其他人工节点保持不变。普通任务只匹配当前已绑定方向，不自动扩建。管理面板“检查可扩展方向”先预览、再明确确认；用户也可绑定已有方向。删除过的方向不会在自动初始化时复活。

当前定义覆盖部分计算机、机器人及交叉研究方向，并非通用学科分类器；独立样本发现机器人记忆案例漏分。超出本地能力时使用人工主题或待整理，不伪称模型判断。本轮不提供模型增强入口，不调用模型、MinerU、OCR、翻译或书目服务。

## 数据及纠正

- `topic_nodes` 保存 owner 范围稳定 UUID、定义、层级、修订、删除及合并重定向；关系和排除独立存储，旧物理分类 ID 不作主题 ID。
- 人工正向关系优先。移出父分支删除直接与后代关系，持续记录分支和节点排除；后来移动节点也不能绕过。明确加入只恢复指定节点。清空设置持续自动保护，只有明确重置解除。
- 合并转移关系、排除和旧 ID 重定向，拒绝祖先后代合并及循环。撤销保留30天操作记录，比较受影响行的后续修订；无关操作可保留，有冲突则拒绝覆盖。长期排除和 tombstone 不随撤销记录到期消失。
- 旧分类幂等迁移为受保护主题关系。旧目录和路径保留；旧物理移动/删除写接口返回410。新 PDF、URL、Daily 和导入使用独立 `topicIds`，新导入集合转为逻辑层级，资产仍放默认目录。
- `topic_pending`、批次/明细/事件记录本地任务；全局两个槽、每用户一个，固定名单最多5000。重启恢复未完成本地项，取消停止后续领取。提交核对正文指纹、已采用内容、主题体系和人工修订；失败保留旧归属。
- 主库保存后查询读取同一关系，不依赖浏览器已加载页或FTS前100条。计数、分页和元数据/关键词/主题批量名单共用查询。

## 运维

完整 SQLite 备份涵盖全部主题表、纠正、任务、操作及导航偏好。主题不新增论文资产副本。部署前停止新任务并备份；回退基线为 Web1.6.0＋Workers1.2.0，继续使用当前数据库，保留新增表。再升级增量对账旧功能的新数据，不覆盖主题纠正。隔离演练使用 `scripts/validate_topics_rollback.py`，禁止在正式数据库运行夹具。
