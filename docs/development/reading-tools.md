# 单篇日常阅读工具（1.4.0）

本页说明功能与限制；发布状态以对应 Release 和部署验收为准。沿用统一阅读器、PDF.js 6.3.289 的 legacy display/worker、自托管资源和阻断式 CSP，没有新常驻服务或运行依赖。

## 搜索与导航

阅读工具栏的搜索按钮或阅读上下文中的 Ctrl/Cmd+F 打开全文搜索；输入框内不接管浏览器快捷键。Enter/Shift+Enter 前后定位，Escape 清除搜索。原文与每个 BabelDOC 文件独立搜索。PDF.js 逐页流式提取，与渲染 DOM 无关；同源搜索 Worker 做连续文字匹配，处理大小写、空白、换行、软连字符和常见连字，保留字符映射。高亮来自实际文本层 Range，无法映射只定位页面。没有文字、提取失败、停止和无匹配分别显示，不自动 OCR。

PDF 文本 LRU 最多 16 页／8 MiB，单页也有文字上限；仅保留每页匹配数量，按需重新读取位置。页面画布仍按可见范围渲染。结构搜索使用所选结果全部块的原文、译文或两者，显示译文覆盖率；每次扫描最多 40 块/100 匹配，签名游标绑定 owner、查询与修订。前端完整扫描，只保留一批匹配正文和轻量游标计数，按需翻批；单标签请求间隔避免高频扫描触发服务端限流。修订变化须重新搜索。正文和来源高亮独立。

左侧目录、缩略图、书签可以折叠。内置 PDF 目录只执行有效内部目标；没有目录时，原始 PDF 可引用当前源版本的结构标题，缺少可靠区域时降为页级。不套用到 BabelDOC。结构目录可直接载入尚未加载的块。目录、书签面板偏好通过现有 owner 工作区接口保存，物理上使用独立设置键，回退到 1.3.0 时旧字段仍能正常写入。

## 书签与临时翻译

书签独立于自动阅读位置，绑定具体文件或结构结果；改名/删除校验修订。每篇最多 200 条、每用户 5,000 条，名称 1–120 字。失效文件禁止定位；旧结构结果仍存在时可以打开原版本，译文变化时降为块首。

原始 PDF 单击可靠段落区域，读取当前结构译文版本的缓存。命中必须满足文档 SHA、结果、页及已验证的 PDF 区域；重叠区域供用户选择，不猜测段落。显示未译/失败状态，永不因单击新建任务。BabelDOC 页面没有原文块映射。

PDF 或结构选区的“翻译”先打开预览，再由用户明确提交。复用结构化翻译配置，不退到 interpret；目标语言可选。PDF 单页选区可由 Document Worker 本地文字检查获得页级来源；无法核实或跨页时明确保留未验证文本，不伪造精确来源。临时译文与整块译文相互独立。

`selection_translate` 接入现有持久调度：每用户一个活动任务、全局模型并发 2、队列最多 20；最多 2,000 Unicode 字符、8,000 输入 token 的保守字节上界、2,048 输出 token、120 秒、一次请求，SDK 自动重试关闭。明确失败/结果未知后需要用户重试。关闭浮层只停止展示与轮询；取消任务停止后续处理，不确认供应商取消或费用。

缓存键包含 owner、论文、文件/结构版本、有效原文、语言、提示词与模型配置修订。可见指针与任务完成状态事务提交，取消前的结果不会覆盖已有块译文。缓存默认 30 天，每用户 2,000 条／64 MiB，并计入总产物配额；终态任务摘要保留，过期后清理临时选中文字。发布过的分析、结构译文不受此清理影响。

## 图表与兼容

结构正文与深度解读中的受控图片、表格、块公式有放大操作。支持适合窗口、缩放、图片平移、表格横向浏览及关闭后恢复焦点/位置。结构图表保留可信原文来源入口。只加载已授权资产；不会下载模型提供的外站图片或调用图像模型。PDF 页面区域仍明确作为原文区域定位，不宣称是提取出的高清图片。

新增 `reading_bookmarks`、`reading_selection_cache`；临时正文复用 `understanding_artifacts`，不改旧论文、聊天、结构表。所有接口经过会话、CSRF、owner、资源版本和大小校验，私有资源不缓存、不返回服务器路径。退出/失效清空搜索、浮层与画布。

测试入口：`pytest tests/test_reading_tools.py tests/test_workspace_state.py`；`npm test`；`playwright test --config playwright.reading-tools.config.ts`。300 页、扫描、无目录 PDF 来源与哈希见 `tests/fixtures/reading-tools/manifest.json`。`tests/verify_reading_selection.py` 默认假供应商，真实模式需单独授权与受控 stdin，不沿用旧版本额度。实际论文证据仅私有保存。
